SMAC Introduction
---
The **Smart Moving Alarm Clock (SMAC)** is a custom alarm clock built for the IEEE SSCS Arduino Contest in summer 2026. 

Problem: When I set an alarm on my phone, I subconsiously snooze it and end up missing my exams.

Solution: A alarm clock that moves so you have to get out of bed and consciously make an effort to shut it off.

Alarms: Can set up to 5 alarms and name them

Clock: Syncs to real time clock from WIFI, offline control through joystick on top 

Audio: Extremely loud alarm through speaker and amplifier

Optional Web App: Control the alarms, weather forecast location (longitude and latitude), and discord webhook information

To turn off the alarm, smack the joystick on top of SMAC.
